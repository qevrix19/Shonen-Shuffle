🃏 Shonen Shuffle
Shonen Shuffle is a massive, anime-themed content expansion for Balatro built on the Steamodded (SMODS) framework.

Bring the power of anime to your next run with a sprawling roster of custom Jokers, entirely new mechanics, and unique consumables inspired by Naruto, Jujutsu Kaisen, Dragon Ball Z, One Piece, Blue Lock, Bleach, Hunter x Hunter, Solo Leveling, Death Note, and Mashle.

✨ Features
100+ Custom Jokers: Build crazy, high-scaling synergies with iconic characters. Scale your High Card X-mult with Obito Uchiha, unleash Godspeed with Killua, or rely on the raw power of Goku, Gojo, Sukuna, Isagi, Light Yagami, Itachi, Sung Jinwoo, and dozens more.

New Consumables: Discover a custom suite of Tarot and Spectral cards, including Sensei, Shinigami, Hunter, Awakening (conditionally destroy a random Joker for a massive boost), and game-changing Domain Expansions.

Anime-Themed Vouchers: Powerful permanent run upgrades tailored to your favorite franchises.

Custom Stakes: Test your skills against new difficulties, including the Super Saiyan Blue-inspired Cyan Stake, which introduces massive scaling and $2 shop inflation.

⚙️ Prerequisites
A legitimate copy of Balatro.

Steamodded (SMODS) installed and functioning.

The Lovely injector (usually included with modern SMODS installations).

📥 Installation
Click the green Code button at the top of this repository and select Download ZIP (or download the latest version from the Releases page).

Extract the Shonen-Shuffle-main folder from the ZIP file.

Rename the extracted folder to exactly Shonen-Shuffle (this ensures asset paths work correctly).

Move the Shonen-Shuffle folder into your Balatro Mods directory:

Windows: %appdata%\Balatro\Mods

Mac: ~/Library/Application Support/Balatro/Mods

Linux: ~/.steam/steam/steamapps/compatdata/2379780/pfx/drive_c/users/steamuser/AppData/Roaming/Balatro/Mods

Launch Balatro. Shonen Shuffle should appear in the Mods menu!
